# Ainulindalë

Ainulindalë is a standalone MIDI note editor for Java.

The project originated from note editor feature exploration in a Maestro fork.

## Current status

In development. The Maven module split and basic canonical domain are implemented alongside the legacy application. See the [domain implementation status](docs/architecture/domain-model.md#current-implementation-status), [module progress and remaining work](docs/architecture/module-architecture.md#implementation-progress-and-remaining-work), and [architecture decisions](docs/decisions/README.md).

## Requirements

- Java 25
- Maven
